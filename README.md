# Real-Time Edge Detection using OpenCV

## Project Overview
This project performs **real-time edge detection** using a webcam with the help of **OpenCV** and **NumPy** in Python.

The program:
- Captures live video from the webcam
- Flips the camera frame
- Converts the frame into grayscale
- Detects edges using the Canny Edge Detection algorithm
- Displays both:
  - Original video
  - Edge-detected video
